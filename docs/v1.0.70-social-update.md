The shareable web profile page (therspshub.com/u/<name> with OG tags) is a good future headliner but too big for this release. Spend the time on more small wins instead.

## Theme unification
Every hardcoded gold accent in the launcher CSS (`#c8a840`/`#ffd070` and the lighter variants `#f4d77c`/`#f0d98a`/`#e0c87a`, ~240 occurrences) now flows from the theme tokens `--accent` / `--accent-hot`. Zero visual change on the default gold theme, but all panels (Hub Chat, Friends, Chat, Activity, cards, etc.) now follow an equipped theme's accent instead of staying stuck gold. This is the "Phase 0 CSS var refactor" the themes system needed.

## Persistence fix (important)
Renderer `localStorage` is unreliable here — a force-kill / ungraceful quit drops unflushed writes, so UI state kept resetting across restarts. Moved all durable client prefs to the Java settings file (`~/.rsps_hub/<user>/profile_settings.json`) via a new `uiPrefs` JSON blob (invite-collapse, pinned chat rooms, server sort). Also added `notifFriendPlaying` to the settings whitelist so that toggle persists. Java: `LauncherEngine` (field + save + load), `ApiServer` (/api/settings GET+POST). Client: `getUiPrefs`/`setUiPref`.
